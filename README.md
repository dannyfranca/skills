# Skills

My reusable agent skills, published through [skills.sh](https://skills.sh/dannyfranca/skills).

## Install

```sh
npx skills add dannyfranca/skills
```

List or install one skill:

```sh
npx skills add dannyfranca/skills --list
npx skills add dannyfranca/skills --skill multi-shot-review
```

## Available skills

- `agent-email` — Email inbox for agent signups, with AgentMail or SMTP.
- `browser` — Browser guidance for agents.
- `explainer-video` — Make a narrated 3Blue1Brown-style explainer video.
- `graceful-pause` — Pause agents without wasting tokens; in-flight multi-shot reviews finish.
- `implement-issues-github` — Implement GitHub issues through to merged PRs.
- `implement-tickets-local` — Implement local tickets with reviews.
- `micro-commits` — Create focused, incremental commits.
- `multi-shot-benchmark` — Compare full review workflows on isolated real historical diffs.
- `multi-shot-review` — Split changes into content slices for repeated harness reviews.
- `multi-shot-review-eval` — Evaluate multi-shot-review A/B tests with independent analyst models.
- `to-tickets-gh` — Publish tracer-bullet tickets as GitHub issues.
- `to-tickets-local` — Publish tracer-bullet tickets as local files.
- `update-codex-await` — Rebase, test, build, and install the long-await Codex fork.
- `why-what` — Write a concise Why / What summary of a change.
- `worktree-janitor` — Clean up expired Git worktrees with recovery snapshots.
- `worktrees` — Apply Git worktree setup conventions.
